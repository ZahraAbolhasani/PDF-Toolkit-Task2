# PDF Toolkit

یک وب‌اپلیکیشن چندمنظوره برای پردازش فایل‌های PDF با رابط کاربری فارسی و RTL.

## ویژگی‌های اصلی

### ۱. تبدیل تصاویر به PDF
- پشتیبانی از فرمت‌های JPG, JPEG, PNG, WEBP
- انتخاب چند تصویر به‌صورت همزمان
- تغییر ترتیب تصاویر
- تنظیم اندازه صفحه (A4, A3, A5, Letter, Legal, یا متناسب با تصویر)
- تنظیم جهت صفحه (عمودی/افقی)
- تنظیم حاشیه صفحات
- انتخاب نام فایل خروجی

### ۲. حذف واترمارک از PDF
- حذف خودکار واترمارک‌های متنی
- حذف واترمارک‌های تصویری
- انتخاب روش حذف (خودکار یا دستی)
- پیش‌نمایش صفحات PDF
- انتخاب صفحات مورد نظر

### ۳. تبدیل PDF به Word
- تبدیل PDFهای متنی به فرمت DOCX
- پشتیبانی از PDFهای اسکن‌شده (در نسخه‌های آینده)
- انتخاب محدوده صفحات
- استخراج متن و تصاویر از PDF

## پیش‌نیازها

### سیستم‌عامل
- Windows 11 (یا Windows 10)
- Python 3.8 یا بالاتر

### نصب Python
1. از وب‌سایت رسمی Python، نسخه 3.8 یا بالاتر را دانلود کنید:
   https://www.python.org/downloads/

2. در هنگام نصب، تیک "Add Python to PATH" را فعال کنید

3. برای بررسی نصب، دستور زیر را در Command Prompt اجرا کنید:
   ```
   python --version
   ```

### نصب وابستگی‌ها
1. در پوشه پروژه، فایل `requirements.txt` موجود است
2. برای نصب خودکار وابستگی‌ها، فایل `setup.bat` را اجرا کنید
3. یا به‌صورت دستی:
   ```
   python -m pip install -r requirements.txt
   ```

## نحوه اجرا

### روش آسان
1. فایل `start.bat` را اجرا کنید
2. مرورگر خود را باز کنید و به آدرس زیر بروید:
   ```
   http://localhost:8010
   ```

### روش دستی
1. ترمینال را در پوشه پروژه باز کنید
2. دستور زیر را اجرا کنید:
   ```
   python backend/main.py
   ```
3. مرورگر خود را باز کنید و به آدرس زیر بروید:
   ```
   http://localhost:8010
   ```

## فناوری‌های استفاده شده

### فرانت‌اند
- **HTML5**: ساختار صفحات
- **CSS3**: طراحی و استایل‌دهی
- **JavaScript (Vanilla)**: تعاملات کاربر

### بک‌اند
- **Python**: زبان برنامه‌نویسی اصلی
- **FastAPI**: فریم‌ورک وب مدرن و سریع
- **Uvicorn**: سرور ASGI برای اجرای FastAPI

### پردازش فایل
- **PyMuPDF (fitz)**: پردازش و دستکاری PDF
- **Pillow**: پردازش تصاویر
- **python-docx**: ایجاد فایل‌های Word

## محدودیت‌ها

### تبدیل تصاویر به PDF
- حداکثر 20 تصویر در هر تبدیل
- حداکثر حجم هر فایل: 50 مگابایت
- فرمت‌های پشتیبانی‌شده: JPG, JPEG, PNG, WEBP

### حذف واترمارک
- حذف واترمارک‌های متنی: خودکار
- حذف واترمارک‌های تصویری: خودکار (با محدودیت)
- حذف واترمارک‌های پیچیده: نیاز به پردازش دستی
- فایل‌های رمزگذاری‌شده: پشتیبانی نمی‌شود

### تبدیل PDF به Word
- PDFهای متنی: پشتیبانی کامل
- PDFهای اسکن‌شده: پشتیبانی محدود (نیاز به OCR)
- حفظ کامل فرمت، جدول، تصاویر و چیدمان: تضمین نمی‌شود

## امنیت و حریم خصوصی

### امنیت فایل‌ها
- اعتبارسنجی نوع فایل با بررسی محتوای واقعی
- محدودیت حجم فایل ورودی
- نام‌گذاری امن فایل‌ها
- جلوگیری از Path Traversal
- عدم اجرای فایل‌های بارگذاری‌شده

### حریم خصوصی
- پردازش تمام فایل‌ها به‌صورت محلی
- عدم ارسال فایل‌ها به سرویس‌های آنلاین
- ذخیره فایل‌ها در پوشه مشخص پروژه
- امکان حذف دستی فایل‌ها

## عیب‌یابی

### خطای "Python not found"
- Python را از وب‌سایت رسمی نصب کنید
- تیک "Add Python to PATH" را در هنگام نصب فعال کنید
- ترمینال را مجدداً باز کنید

### خطای "Module not found"
- وابستگی‌ها را با دستور زیر نصب کنید:
  ```
  python -m pip install -r requirements.txt
  ```

### خطای "Port 8010 already in use"
- سرور دیگری در حال اجرا است
- پورت را تغییر دهید یا سرور دیگر را متوقف کنید

## اجرا روی لینوکس و مک

این پروژه کاملاً چندسکویی است. روی لینوکس/مک کافی است:

```bash
chmod +x start.sh
./start.sh
```

اسکریپت `start.sh` خودش محیط مجازی می‌سازد، وابستگی‌ها را نصب می‌کند و سرور را روی
`http://127.0.0.1:8010` بالا می‌آورد (معادل همان کاری که `start.bat` در ویندوز می‌کند).

> **نکته مهم:** پوشه‌ی `venv/` و فایل‌های `__pycache__/` مخصوص همان سیستم‌عاملی هستند که
> ساخته شده‌اند و به‌هیچ‌وجه نباید بین سیستم‌عامل‌ها کپی یا ارسال شوند.
> برای اشتراک‌گذاری پروژه فقط همین سورس + `requirements.txt` کافی است.
